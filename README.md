MomBossWellness Brand Assets
This repository is the central home for MomBossWellness LLC's visual identity, including logo files, brand marks, color palette, and typography. Use these assets to keep all MomBossWellness materials consistent across web, print, and social channels.

Logos & Marks
The primary logo lives in MOMBOSS Wellness Logo Color.svg, with a black-and-white version (MOMBOSS Wellness Logo BW.svg) and a fully editable vector version (MOMBOSS Wellness Logo Vector Editable.svg) also included. Social-optimized variants are available in Deep Green, Gold, and Purple, plus a general social color version.
The brandmark (icon-only version of the logo) is provided in MBW Brandmark.svg, with black-and-white and social color variants in Deep Green, Gold, and Purple. A matching submark (a simplified, smaller-scale mark) follows the same naming pattern, including a version designed for use on the "Grove" background (MBW Submark Social on Grove.svg).
The wordmark (text-only treatment of the brand name) is available in Workmark Color.svg, with black-and-white and social variants in the same three brand colors, plus a Grove-background version for social placement.
A dark-background submark for social and digital use (not print) is in Brand/Logo/Social (MBW Submark Social on Dark.svg and .png). It is made for Rooted Evergreen and Deep Grove backgrounds.
MBW Avatar for IG.svg is sized and cropped for use as an Instagram profile photo.

Color Palette
MBW Color Palette.png documents the official brand colors, including the Deep Green, Gold, and Purple used across the logo variants.

Fonts
Three type families make up the MomBossWellness type system: Montserrat (Regular and Italic, variable weight) for body and supporting text, Quicksand (Light, Regular, Medium, SemiBold, and Bold) as a versatile display and UI typeface, and Parisienne (Regular) as a script accent font for decorative use.

Usage Notes
Please use the color and social-optimized variants for their intended platforms, and default to the BW versions when a single-color mark is required.


Icons
Brand/Icons/MBW Line Icons holds 48 line icons (SVG and PNG) covering the wellness realms of the five mom personas, with icon-guide.json listing each one.

Design System
The design-system folder holds everything needed to build the website and apps on brand: tokens (JSON and CSS), a Tailwind theme, fonts, logos, icons, React components, and system.md with the usage rules. For Lovable and developer handoff, use the dedicated mombosswellness-design-system repo, which is laid out the way Lovable reads a design system.
